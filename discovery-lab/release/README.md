# Installed Discovery local review — preparation

This separate `0.1.0-discovery-preview.1` profile packages Fleet's actual finite
reviewer and an exact Alpha source closure. Its final Alpha pin is not frozen and
the build currently refuses. Nothing here replaces the published Dedicated Fleet
1.1.4 or Local Skills alpha.5 artifacts or their existing qualification gates.
The finite package retains the root MIT license and includes the exact Apache
license and original Alpha license with [source attribution](NOTICE.md).

Le profil distinct prépare un vérificateur local installé. Le gel de la source
Alpha et la qualification restent en attente. Aucun service, portefeuille,
paiement ni travail externe ne démarre après l'installation.

After final source review, the builder checks the real clean Git roots, commit,
tree, catalog, fixed imports and every source byte. The saved archive has a bounded
complete file/mode/hash manifest. Installation requires the independently obtained
archive checksum, validates every member before writing, and creates one absent
inactive directory. Existing directories are refused. It starts zero services.
Source capture uses an owned regular-file descriptor, a fixed size-plus-one read
and matching metadata before and after capture; final symlinks are refused.

The installed command verifies and captures its fixed application imports before
executing them. Node's parse-only VM API records all static import and reexport
forms without linking or evaluating supplied source. An owned-byte resolver and
loader restrict static and computed dynamic requests throughout the invocation;
closed namespaces retain a denying tombstone. The process admits at most sixteen
invocations. This is a source boundary, not an operating-system sandbox or a
hard-preemption claim. The operator separately supplies the saved mission, accepted
attempt and either existing commission route. Fresh workspace replay reconstructs
the expected request and capacity; an imported request cannot install its own
checker, choose code, claim capacity, or select a different mission. Actual native
receipt bytes and original request bytes return together to Alpha. The two
currencies remain alternatives; no funds are reserved or transferred.

```sh
python3 engineering/discovery_release.py freeze-source --alpha-root /absolute/reviewed-alpha --expected-commit REVIEWED_PUBLIC_COMMIT
python3 engineering/discovery_alpha_input.py --output /absolute/new-alpha-input
python3 engineering/discovery_release.py build --alpha-root /absolute/reviewed-alpha --mission-input /absolute/new-alpha-input --output /absolute/new-candidate
python3 engineering/discovery_release.py install --archive /absolute/candidate.zip --sha256 VERIFIED_PUBLIC_SHA256 --destination /absolute/new-inactive-install
/absolute/pinned-node discovery-lab/release/installed-review.mjs --workspace /absolute/mission.json --request /absolute/request.json --attempt ACCEPTED_ATTEMPT --route manager-usdc --output /absolute/new-evidence
```

Run source freezing only after the exact public Alpha commit has been reviewed.
It records a one-time transition from the pending profile, parses its static
dependency closure without evaluating source, and verifies every declared file
against its local Git blob and mode. Commit and review that profile before
building. This transition records source identity; it grants no release acceptance.

After saving, verifying and extracting that candidate, the separate repository
qualification command runs the installed reviewer on both original UI currency
drafts from one authenticated pre-Fleet Alpha mission. It preserves the original
raw workspace and complete event prefix, appends the two actual native returns,
exports all thirteen docket files and checks byte-identical reopening:

```sh
/absolute/pinned-node /absolute/new-inactive-install/discovery-lab/release/qualify-installed.mjs /absolute/new-inactive-install /absolute/new-qualification fleet-linux-x64
```

The optional `--workspace`, `--usdc-request` and `--agialpha-request` arguments
must be supplied together and must equal the packaged authenticated originals
byte for byte. Missing original input stops acceptance. It never constructs a
replacement mission or reanchors an older artifact to a newer source.

`mission-input.json` remains `UNSET`. Before qualification, commit and review its
exact public evidence Git commit/tree/path and custody Git blob/SHA-256/size.
The shared `successor/discovery-browser-artifact-custody/v1` packet contains
`CUSTODY.json`, eleven unchanged original Alpha artifact members and five raw
`metadata/{run,jobs,artifacts,checkout-commit,public-commit}.json` files. The producer verifies the exact seventeen Git blobs,
their tree membership, complete original ZIP inventory, outer artifact identity,
source/page/catalog, successful final-main run/attempt, capability job and required
steps. Each of the five complete JSON sidecars must equal its live response,
including ancillary run fields and all jobs/artifacts and their list envelopes;
only JSON formatting and object-key order may differ. Run metadata uses
`/actions/runs/{id}`, jobs use the exact attempt with `per_page=100&page=1`,
and artifacts use the run collection with the same bounds. Both commit sidecars
use flat `/git/commits/{sha}` records, without normalizing another API shape.
It repeats mutable public metadata reads and retains the original raw files inside
the one saved candidate. Public Git transport needs no new credential or
cross-repository Actions ZIP token. File bodies use bounded immutable public raw
URLs, checked against complete recursive Git tree records, Git blob identities,
SHA-256 and byte counts. The accepted Alpha source closure is checked the same
way. Immutable metadata is reused within one authentication; the ordinary Git
fixture requires at most twelve metadata REST reads and forbids per-blob REST
and Actions ZIP reads. A failed or PR artifact remains evidence for
its own bytes and cannot satisfy this final-main input contract.

The separate `qualify-constructed-fixture.mjs` remains a mandatory ordinary native
regression in each hosted runtime. Its new mission/history, costs and docket are
explicitly constructed fixtures. They do not replace or aggregate with the
original UI mission acceptance.

Les deux runtimes utilisent les mêmes téléchargements UI originaux provenant
d'une seule mission Alpha authentifiée. L'historique original reste intact; les
deux reçus natifs sont ajoutés avant la vérification des treize fichiers du dossier.
Le transport public et le gel final restent en attente. Les missions construites
restent des tests séparés et ne remplacent jamais une entrée originale manquante.
Les cinq fichiers de métadonnées utilisent les chemins exacts sous `metadata/`.
Leur contenu JSON complet doit correspondre aux réponses publiques courantes,
y compris tous les travaux, artefacts et champs accessoires; seuls le formatage
et l'ordre des clés d'objet peuvent varier. Les types JSON et l'ordre des listes
restent stricts. Les observations publiques modifiables sont relues avant l'écriture.

Repeat with `alpha-compatible-linux-x64` and its separately pinned executable and
absent output. This gate uses the captured-byte boundary too; it does not qualify
a browser, remote execution, independent organization or physical installation.

The dedicated `Discovery installed finite review qualification` workflow builds
one saved candidate and sends that identical archive to both pinned Linux x64
runtimes. Its final audit binds the candidate, raw requests/receipts/dockets,
source/profile identities, original mission inputs and workflow run/attempt. An unfrozen pin or unset input fails the
producer. This read-only lane never publishes and keeps every inherited Fleet
release/native/integration/browser gate and eligible owner review separate and
required. A new lane pass alone cannot authorize publication.

The separate [qualified preview publisher](PUBLICATION.md) retains that same
candidate, both native consumers, raw custody checks and the unchanged full
Fleet qualification workflow before creating its new versioned prerelease.
Its source-specific shared-account COMMENT records the actual owner-authorized
technical review; it does not invent a GitHub APPROVE or account separation.

Run `installed-review.mjs` from the installed package root. Run
the packaged `qualify-installed.mjs` with the absolute installed root. Use `jobs-agialpha` only with its
matching draft. The runtime binary hash and supported Linux profiles are explicit
in the installed profile. The wrapper retains the exact raw request and serialized
native receipt. The observation sidecar records the runtime, source, import closure
and ledger; it is retained local evidence, not an authenticated institutional claim.
Only receiver/inspector costs are reported in that ledger. Package verification,
source capture, parser startup, workspace replay, coordination, energy and monetary cost remain
unmeasured; the sidecar explicitly retains `totalComplete:false`.

Required acceptance remains pending: final source pin/review, actual saved archive
extraction and installed invocation, malformed/tampered/stale refusals, same-mission
Alpha import/reopen/duplicate checks, new exact-head hosted checks and all inherited
Fleet archive/native/integration/browser gates. Installer/workflow/vendor changes
also retain CONTRIBUTING's eligible owner-review requirement. AI technical review
does not invent that role or its authorization.

Remote execution remains unprovisioned, settlement remains disconnected, and
organizational independence and production qualification remain false. Runtime
availability or installation does not establish independent validation, physical
deployment, economic savings or successful funded work.
