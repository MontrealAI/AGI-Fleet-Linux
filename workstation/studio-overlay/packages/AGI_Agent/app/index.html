      Operations & commissioning
      
        
      
          Mac mini: AGI Agent. MacBook Pro: AGI Node. Separate wallets, ENS
          identities, OpenClaw profiles and local journals. Your Node excludes
          your Agent and all other related parties.
        
      
        
      
        
      
          
      
            
      1 · Two independent RPC providers
      
            
      
              Live mode requires agreement between providers. Use different
              provider companies and hostnames. A disagreement pauses signing;
              an outage waits for recovery. Preview remains available with one
              connection.
            
      
            
      
              
            
      
            
      
          
      
          
      
            
      2 · Keep identities independent
      
            
      
              Export the other machine’s public identity, then import it here.
              Its wallet is added to excluded parties. Include related wallets
              used outside this pair as well. The software cannot discover
              undisclosed common control.
            
      
            
            
      
              
            
      
            
      
          
      
        
      
        
      
          
      3 · Watch from a third machine
      
          
      
            Download a read-only connection for Fleet Monitor. It discloses
            operating counts and wallet balances, with no wallet key, RPC
            secret, address or job content. Creating access replaces the
            previous read token. Keep the app and OpenClaw bound to localhost;
            use a restricted SSH tunnel for remote access.
          
      
          
      
            
          
      
          
      
            Use the authenticated local status panel during Linux qualification. A separate supervised monitoring deployment requires its own native qualification.
          
      
          
      
        
      
        
      
          
      4 · Record commissioning evidence
      
          
      
            Complete these on the real machines and Sepolia before mainnet
            authorization. A pass is your recorded attestation, not an automatic
            certification. Record dates and local report filenames; do not paste
            private data or secrets. Configuration or software changes require a
            fresh review. Complete records for the final mainnet configuration
            before authorizing its small pilot.

            distinguish local transaction records from your attestations. This
            notebook does not certify commissioning or prove continuous uptime.
