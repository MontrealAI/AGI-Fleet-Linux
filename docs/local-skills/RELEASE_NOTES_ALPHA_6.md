# Local Skills alpha.6 source candidate

This new bounded Linux development preview includes the explicit current
Manager 1.19.3 artifact profile, corrected alpha.5 publication guidance and
an optional Alpha Computer Use route through the existing local service.
It retains the existing project request, separately authorized Agent execution,
internal Node check and historical return. The Manager USDC and Jobs v0
$AGIALPHA routes remain explicit and unfunded. Use public, non-personal inputs
only.

Use the [version-matched EN/FR download guide](DOWNLOAD_ALPHA_6.md) after the
named release assets are published following exact-package qualification.
The source identity is `0.1.0-alpha.6`, with a new tag and archive; no alpha.5,
alpha.4 or Dedicated Fleet asset is replaced. All current local module tests,
native/saved-installation checks on both architectures, EN/FR browser checks,
the inherited Fleet regression suite and evidence audits remain mandatory.
Publication also requires the exact saved package to execute the native
Computer Use service journey, retain its same-project Alpha return and real
browser artifacts, and complete both disposable mock-token lifecycles.

The optional route is disabled by default. An operator separately installs
an exact-source Docker/Python profile bound to one public, non-personal Alpha
handoff and a fixed bounded action sequence. The dashboard prepares a task;
activation, an exact one-use grant and execution remain separate decisions.
This route is a scripted browser rehearsal with zero provider requests and
known zero provider cost. Live paid providers are denied before invocation.
It does not qualify general browser/desktop automation, native Mac execution,
independent economic review or live signing/settlement. See the
[operator configuration guide](../../local-runtime/computer/README.md).

[Cost observations have explicit scopes](DOWNLOAD_ALPHA_6.md#reading-the-cost-observations):
Manager's fourteen lifecycle gas receipts exclude deployment/setup, while Jobs
counts all mined fixture receipts, including deployment/setup. The nine CLI
commands cover the service sequence only. Human/device cost remains unknown;
no savings, invoice verification or cost-superiority claim is made.

`operatorInstaller`, `fullHandoffComplete` and `productionQualified` remain
false. The original 22 complete-product acceptance cases remain open.
Physical, live-provider, human-accessibility and endurance commissioning
remain NOT_RUN, and funded work remains disabled.

## Français

Ce candidat alpha.6 ajoute le profil explicite des artefacts Manager 1.19.3
et corrige les indications sur la publication alpha.5. Il ajoute un parcours
Alpha Computer Use facultatif dans le service local existant. Le parcours Agent,
la vérification Node interne et l’historique sont conservés; les routes USDC
et $AGIALPHA restent explicites et non financées. Utilisez seulement des
données publiques non personnelles et le [guide EN/FR alpha.6](DOWNLOAD_ALPHA_6.md).

Cette nouvelle archive exige ses propres essais et audits sur x64/ARM64,
y compris le service installé, le navigateur réel, le retour vers le même
projet Alpha et les deux cycles de jetons simulés sur des chaînes jetables.
Les anciens fichiers demeurent inchangés. Le parcours facultatif reste
désactivé par défaut et exige un profil local installé séparément, des données
publiques non personnelles et une autorisation exacte à usage unique.
Cette répétition scénarisée ne fait aucune requête fournisseur; son coût
fournisseur est nul. Les fournisseurs payants sont refusés avant invocation.
Aucun moteur général de navigateur/bureau, mode local Mac, signataire réel
ni examen économique indépendant n’est qualifié. Les 22 critères complets restent ouverts;
les essais physiques, d’accessibilité humaine et d’endurance restent non
réalisés. Le travail rémunéré et la qualification de production restent
désactivés.

Les [mesures de coût](DOWNLOAD_ALPHA_6.md#français) gardent leurs périmètres :
quatorze reçus de cycle Manager sans déploiement/configuration, tous les reçus
minés Jobs avec déploiement/configuration, et neuf commandes CLI du service
seulement. Les coûts humains et matériels restent inconnus; aucune économie,
facture vérifiée ni supériorité de coût n’est revendiquée.
