# Local Skills alpha.5 source candidate

Alpha project history can now move through bounded Fleet execution and a
separately authorized internal Node check, then return to the same Alpha project.
The exact upstream request, original native project, unit-preserving CSV task,
explicit USDC or $AGIALPHA route and both receipts stay together. The local
dashboard exposes the complete EN/FR import, prepare, authorize, run, check and
save-return workflow. [Project guide](PROJECT_JOURNEY.md).

An execution is bound to the exact project request in its reviewed grant,
reservation and receipt. Identical CSV tasks cannot transplant work between
different project IDs, cycles or payment routes. The portable checker validates
the retained project, task, files and internal check without claiming controller
identity or independent review. Whole attached Manager/Jobs histories remain
unverified here and must pass their native stage receivers.

The dashboard also supplies an actionable bilingual no-JavaScript notice and
keeps initial connection controls disabled until the application is loaded.
Wrapping fixes support narrow screens and enlarged text without clipping.

This candidate uses `0.1.0-alpha.5` and a new release tag/archive identity.
Published alpha.4 and Dedicated Fleet Linux/Mac assets are unchanged. The
preserved alpha.4 specification retains its original 127-test source gate;
alpha.5 requires 135 module tests and retains the native, installer, browser,
inherited Fleet and independent audit gates. No threshold is reduced.

The source has eight added project regressions, covering EN/FR, both routes,
separate authorization, invalid input/receipt changes and cross-project replay.
Component, fixture and fallback-browser observations do not qualify an operator
distribution. The exact saved candidate still needs x64 and ARM64 native and
installed journeys, the pinned browser gate and retained audit. Physical,
live-provider and independent economic-review commissioning remain open.
Production qualification is false and funded work is disabled.

## Français

L'aperçu source alpha.5 conserve le même projet Alpha pendant une exécution
Fleet limitée et une vérification interne Node autorisée séparément. Le tableau
de bord permet l'importation, l'examen des permissions et l'enregistrement du
retour. Les routes USDC et $AGIALPHA restent explicites, sans conversion,
affectation de contrat ni paiement. Les octets d'origine et les deux reçus sont
conservés. Les travaux identiques de projets, cycles ou routes différents ne
peuvent pas réutiliser une même autorisation de projet.

Les historiques Manager/Jobs joints restent non vérifiés par Fleet; leurs
récepteurs natifs doivent les valider. Le retour importé est une preuve interne
historique, pas une permission ni un examen économique indépendant. Les
versions publiées alpha.4, Linux et Mac sont inchangées. La nouvelle archive
requiert sa propre qualification; la production et les travaux financés restent
désactivés.
