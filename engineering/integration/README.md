# Four-repository native computer compatibility

This additive engineering lane composes existing source APIs. Alpha's current
project-bound Computer Use handoff, journal, reservation, native worker and
signed return remain authoritative for their own semantics. Jobs' existing
supplier strategy engine supplies the frozen mission and recomputes actual
browser output. Separate Manager USDC and Jobs AGIALPHA adapters prepare
unfunded proposals. Alpha retains the complete handoff and native return with
human review still pending. Fleet's engineering runner coordinates this rehearsal.
The separate optional LocalRuntime backend supports explicitly installed,
zero-cost scripted profiles; live paid providers remain uncommissioned.

The finite synthetic supplier case compares a single early supplier, split
delivery and bounded integer allocation. Its approved fixture formulation
retains ten units by day seven, forty by day fourteen and the original budget.
Qualification requires entering the frozen candidate using real mouse/keyboard
actions in Chromium. A separate arithmetic implementation checks requirements and costs.
Scripted advice is disclosed throughout. This proves bounded actuator, receipt
and draft compatibility; it does not prove live model research quality,
protected evaluation, independently controlled economic review, realized savings
or paid commissioning.

Use exact clean checkouts selected in `compatibility-set.json`. The hosted
runner compares every imported source file against the selected HEAD Git blob,
rejects linked or untracked importable files, and checks the complete source
snapshot again after execution. Ignored interpreter caches are explicitly
excluded from inventory; Alpha SDK imports compile captured bytes checked against
the pinned Git objects. The offline audit independently derives the complete SDK
count, byte total and digest from those objects and requires an exact match.
Installed third-party dependencies retain a source-only loader and fresh empty
bytecode-cache prefix; the interpreter and native dependencies remain trusted
installed runtime. Git replacement refs and
filesystem-monitor hooks are disabled for source verification, and Node preload
environment variables are not inherited. The host dependency lock contains fourteen unmodified package blocks
from Alpha's existing hash-locked agent profile; installs require those hashes.
The hosted
workflow builds Alpha's existing reviewed Dockerfile, records the resolved base
image RepoDigest and local immutable image ID, and binds that image ID into the
native permit and signed receipt. Resolving a tag before recording its digest
does not establish cross-time reproducibility; retain the observed base digest
for an exact replay. There is no host fallback in the Docker command.
The source-kit ZIP packages the exact helper Git bytes, their compatibility
inputs and the shared installed SDK-capture launcher. Its extracted capture path
is checked before image build; it requires the four source checkouts and is not
a Fleet installer.
After the real browser result passes both native receivers, the same exact

The positive paths observe actual mock-token payouts. Jobs' negative path
