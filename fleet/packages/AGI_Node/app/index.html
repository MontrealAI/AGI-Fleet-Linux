    Useful boundaries

    Studio uses offline public inputs and a disposable work desktop. Use the dedicated commissioning panel to test protected browsing. Accepted browser jobs also require approved website permissions and a current, reviewed qualification receipt. Private accounts and your personal desktop use the separate, explicitly authorized workstation workflow; this Studio stays isolated from them and your wallet.

    Quick editor: up to 4 MiB of output. General v2 imports: up to 64 files, 32 MiB each and 64 MiB total. Each task keeps its own smaller declared limits. Allow up to 192 MiB of local storage per saved run, including revision originals; download and remove old runs when needed.

                  discover undisclosed common control.

                previous read token. Keep the app and OpenClaw bound to
                localhost; use a restricted SSH tunnel for remote access.
